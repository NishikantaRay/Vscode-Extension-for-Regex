# Contributing to Regex Snippets Plus\n\n🎉 Thank you for your interest in contributing! We welcome contributions from the community.\n\n## 📋 Table of Contents\n\n- [Code of Conduct](#code-of-conduct)\n- [Getting Started](#getting-started)\n- [How to Contribute](#how-to-contribute)\n- [Development Setup](#development-setup)\n- [Submitting Changes](#submitting-changes)\n- [Style Guidelines](#style-guidelines)\n\n## 🤝 Code of Conduct\n\nBy participating in this project, you agree to abide by our Code of Conduct. Please treat all contributors with respect.\n\n## 🚀 Getting Started\n\n### Ways to Contribute\n\n1. **Report Bugs** - Found an issue? Let us know!\n2. **Suggest Features** - Have an idea for improvement?\n3. **Add Regex Patterns** - Contribute new validation patterns\n4. **Language Support** - Add snippets for new programming languages\n5. **Documentation** - Help improve our docs\n6. **Code Improvements** - Optimize performance or fix bugs\n\n## 🛠️ Development Setup\n\n### Prerequisites\n\n- [Node.js](https://nodejs.org/) (v14 or higher)\n- [VS Code](https://code.visualstudio.com/)\n- [Git](https://git-scm.com/)\n\n### Setup Steps\n\n1. **Fork the repository**\n   ```bash\n   git clone https://github.com/YourUsername/Vscode-Extension-for-Regex.git\n   cd Vscode-Extension-for-Regex\n   ```\n\n2. **Install dependencies**\n   ```bash\n   npm install\n   ```\n\n3. **Build the extension**\n   ```bash\n   npm run compile\n   ```\n\n4. **Test the extension**\n   - Press `F5` in VS Code to launch Extension Development Host\n   - Test your changes in the new VS Code window\n\n## 📝 How to Contribute\n\n### Adding New Regex Patterns\n\n1. **Choose the appropriate file:**\n   - `snippets/snippets.code-snippets` - General patterns\n   - `snippets/python-regex.code-snippets` - Python-specific\n   - `snippets/php-regex.code-snippets` - PHP-specific\n   - etc.\n\n2. **Follow the pattern format:**\n   ```json\n   {\n     \"Pattern Name\": {\n       \"prefix\": \"!trigger\",\n       \"body\": [\n         \"pattern or code lines\"\n       ],\n       \"description\": \"Clear description of what this pattern validates\"\n     }\n   }\n   ```\n\n3. **Test your pattern:**\n   - Ensure it works correctly\n   - Test with edge cases\n   - Verify the description is accurate\n\n### Adding Language Support\n\n1. **Create a new snippet file:**\n   ```\n   snippets/[language]-regex.code-snippets\n   ```\n\n2. **Update `package.json`:**\n   ```json\n   {\n     \"language\": \"newlanguage\",\n     \"path\": \"./snippets/newlanguage-regex.code-snippets\"\n   }\n   ```\n\n3. **Follow language conventions:**\n   - Use appropriate syntax for the language\n   - Include proper imports/dependencies\n   - Add error handling where applicable\n\n### Adding Form Components\n\n1. **Add to appropriate file:**\n   - `snippets/form.code-snippets` - Basic form fields\n   - `snippets/formsgroup.code-snippets` - Form groups\n   - `snippets/advanced-forms.code-snippets` - Complex forms\n\n2. **Use Bootstrap 5 standards:**\n   - Follow Bootstrap 5 component structure\n   - Include proper validation classes\n   - Add accessibility attributes\n\n## 🎨 Style Guidelines\n\n### JSON Files\n- Use 4 spaces for indentation\n- Use double quotes for all strings\n- Add descriptions for all snippets\n- Keep trigger prefixes consistent (`!` prefix)\n\n### Code Snippets\n- Use meaningful variable names\n- Include proper error handling\n- Add comments where helpful\n- Follow language-specific conventions\n\n### Documentation\n- Use clear, concise language\n- Include examples where possible\n- Keep formatting consistent\n- Update README when adding new features\n\n## 📤 Submitting Changes\n\n### Pull Request Process\n\n1. **Create a feature branch:**\n   ```bash\n   git checkout -b feature/your-feature-name\n   ```\n\n2. **Make your changes:**\n   - Follow the style guidelines\n   - Test thoroughly\n   - Update documentation\n\n3. **Commit your changes:**\n   ```bash\n   git add .\n   git commit -m \"feat: add new email validation pattern\"\n   ```\n\n4. **Push to your fork:**\n   ```bash\n   git push origin feature/your-feature-name\n   ```\n\n5. **Create a Pull Request:**\n   - Use a descriptive title\n   - Explain what you changed and why\n   - Link to any related issues\n\n### Commit Message Format\n\nUse conventional commits format:\n\n```\ntype(scope): description\n\n[optional body]\n\n[optional footer]\n```\n\n**Types:**\n- `feat`: New feature\n- `fix`: Bug fix\n- `docs`: Documentation changes\n- `style`: Code style changes\n- `refactor`: Code refactoring\n- `test`: Adding or updating tests\n- `chore`: Build process or auxiliary tool changes\n\n**Examples:**\n- `feat: add JWT validation pattern`\n- `fix: correct email regex for international domains`\n- `docs: update README with new language support`\n\n## 🧪 Testing\n\n### Manual Testing\n1. Install the extension in development mode\n2. Test all new snippets\n3. Verify existing functionality still works\n4. Test in different file types\n\n### What to Test\n- Snippet triggers work correctly\n- Generated code is valid\n- Descriptions are accurate\n- No conflicts with existing snippets\n\n## 📋 Issue Guidelines\n\n### Bug Reports\nInclude:\n- VS Code version\n- Extension version\n- Steps to reproduce\n- Expected vs actual behavior\n- Screenshots if applicable\n\n### Feature Requests\nInclude:\n- Clear description of the feature\n- Use case/rationale\n- Examples if applicable\n- Any alternatives considered\n\n## 🙏 Recognition\n\nContributors will be:\n- Listed in the CONTRIBUTORS.md file\n- Mentioned in release notes\n- Given credit in documentation\n\n## 📞 Getting Help\n\n- **Questions?** Open a [Discussion](https://github.com/NishikantaRay/Vscode-Extension-for-Regex/discussions)\n- **Bug?** Open an [Issue](https://github.com/NishikantaRay/Vscode-Extension-for-Regex/issues)\n- **Chat?** Join our community discussions\n\nThank you for contributing to Regex Snippets Plus! 🚀"
